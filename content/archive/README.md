# Rejected and archived material

Move rejected records or obsolete drafts here when freeing a production position.
Keep the rejection reason and prior review history. Files in this directory are
never imported by the game or included in the production validation/release set.
Remove or update any equivalence links to a moved record: production references
must resolve within `content/production/puzzles.json`.

Do not remove already released puzzle IDs from the release baseline. Published
content changes require a higher revision and a fresh editorial approval.
